# รายการที่ต้องลองด้วยมือ

ระบบทดสอบอัตโนมัติ 932 ตัวครอบเกือบทุกอย่างแล้ว **ยกเว้น 2 เรื่องนี้** ที่ต้องมีคนกดจริง
เพราะมันต้องใช้หน้าจอจริง (คลิก, วาง, พิมพ์) หรือปลายทางจริง (กล่องอีเมล)

ใช้เวลาประมาณ 10 นาที ทำทีเดียวหลังแก้อะไรที่เกี่ยวข้อง

## 1. หน้า "บันทึกข้อมูล" — การวางจาก Excel

> ⚠️ ส่วนนี้เคยพังแบบ **เงียบสนิท** มาแล้ว: วางแล้วไม่มีอะไรเกิดขึ้น ไม่มีข้อความเตือน
> และไม่มีเครื่องมือไหนจับได้เลย (เทสต์เขียวหมด) — จึงต้องลองด้วยตาทุกครั้งที่แก้หน้านี้

เตรียม: เปิดหน้า "➕ บันทึก" แล้วกดแท็บ "กรอกหลายวัน"

| ลองอะไร | ต้องได้อะไร |
|---|---|
| คัดลอกจาก Excel 3 คอลัมน์ (วันที่ · ยอดขาย · ค่าแอด) **พร้อมแถวหัวตาราง** แล้ววางที่ช่องวันที่แถวแรก | ข้อมูลลงครบทุกแถว **หัวตารางไม่ถูกนับเป็นข้อมูล** |
| กดปุ่ม "เติมวันที่ขาด" ก่อน แล้วคัดลอก**เฉพาะคอลัมน์ยอดขาย**จาก Excel มาวางที่ช่องยอดขายแถวแรก | ยอดลงตรงวัน ไม่เลื่อน · ถ้ามีหัวตารางติดมาต้องถูกข้าม |
| วางโน้ต 3 บรรทัดลงคอลัมน์โน้ต | ลงครบ 3 แถว **แถวแรกไม่หาย** |
| วางข้อมูลที่กว้างเกิน 4 คอลัมน์ | ขึ้นคำเตือนว่าล้นออกไป ไม่ใช่ทิ้งเงียบ |
| วางวันที่แบบ `05/03/2026` (อ่านได้ทั้ง 5 มี.ค. และ 3 พ.ค.) | ช่องวันที่**เว้นว่าง** + ขึ้นคำเตือน ไม่ใช่เดาให้ |
| พิมพ์วันที่ที่**มีข้อมูลอยู่แล้ว**ลงในแถว | ยอดและโน้ตเดิมของวันนั้นถูกเติมมาให้เห็น |
| พิมพ์วันที่ใน**อนาคต**ลงในแถว | ขึ้นคำเตือนว่าเติมค่าเดิมให้ไม่ได้ |
| กดปุ่ม "เติมวันที่ขาด" ตอนที่ตารางมีข้อมูลอยู่ | **ถามก่อน**ว่าจะล้างตารางไหม |
| เปลี่ยนเดือนของตารางเป็นเดือนอนาคต | ช่องเลือกเดือนเด้งกลับมาเป็นเดือนปัจจุบัน (ไม่ใช่ค้างที่เดือนอนาคตแต่โชว์ข้อมูลเดือนนี้) |

**ถ้าข้อไหนไม่เป็นไปตามนี้** — เปิด Console ของเบราว์เซอร์ (กด F12 → แท็บ Console)
ถ้ามีข้อความสีแดง ให้คัดลอกมาทั้งบรรทัด นั่นคือต้นตอ

## 2. อีเมลรีเซ็ตรหัสผ่าน

ระบบตรวจได้แค่ว่า "ตั้งค่าครบไหม" — **ส่งถึงกล่องจดหมายจริงหรือเปล่า ตรวจแทนไม่ได้**

1. หน้า "ลืมรหัสผ่าน" → กรอกอีเมลจริงที่ใช้อยู่ → กดส่ง
2. เปิดกล่องจดหมาย (ดูโฟลเดอร์ Junk/Spam ด้วย)
3. กดลิงก์ในอีเมล → หน้าต้องบอกว่า **"กำลังตั้งรหัสผ่านใหม่ให้บัญชี &lt;อีเมลของคุณ&gt;"**
4. ตั้งรหัสใหม่ → เข้าสู่ระบบด้วยรหัสใหม่ได้
5. ลองกดลิงก์เดิม**ซ้ำอีกครั้ง** → ต้องใช้ไม่ได้แล้ว

ไม่ได้รับอีเมล = ตั้งค่า SMTP ไม่ครบ (`MAIL_ENABLED`, `MAIL_USERNAME`, `MAIL_PASSWORD`,
`MAIL_FROM_ADDRESS` ต้องมีครบทั้ง 4)

## ทำไมสองเรื่องนี้ถึงอัตโนมัติไม่ได้

- **การวาง**: ต้องมีเบราว์เซอร์จริงที่มีคลิปบอร์ด — ระบบทดสอบตรวจได้แค่ว่าโค้ดอ่านค่าถูก
  และไม่มีฟังก์ชันที่เรียกแล้วไม่มีอยู่จริง แต่ตรวจไม่ได้ว่า "วางแล้วลงตรงช่อง"
- **อีเมล**: ต้องมีกล่องจดหมายจริง — ระบบตรวจได้แค่ว่าคอนฟิกครบและสร้างลิงก์ถูก
