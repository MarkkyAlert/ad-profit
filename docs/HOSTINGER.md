<a name="ก่อนเริ่ม"></a>
## ก่อนเริ่ม — เตรียม 4 อย่างใน hPanel

### 1. ตั้งเวอร์ชัน PHP เป็น 8.3 ขึ้นไป

hPanel → **Advanced** → **PHP Configuration**

⚠️ **ต่ำกว่า 8.3 ติดตั้งไม่ผ่านตั้งแต่แรก** (ไลบรารีทำไฟล์ Excel บังคับ 8.3)

### 2. เปิดส่วนเสริมที่ต้องใช้

แท็บ **PHP Extensions** ในหน้าเดียวกัน · ที่ต้องมี:

| ส่วนเสริม | ใช้ทำอะไร | มักปิดไว้ไหม |
|---|---|---|
| `pdo_mysql` | ต่อฐานข้อมูล | เปิดอยู่แล้ว |
| `mbstring` | ตัวอักษรไทย | เปิดอยู่แล้ว |
| **`zip`** | **ไฟล์ Excel** | ⚠️ **บางแพ็กเกจปิดไว้** |
| **`gd`** | **ไฟล์ Excel** | ⚠️ **บางแพ็กเกจปิดไว้** |
| `dom` `xml` `simplexml` `xmlreader` `xmlwriter` `zlib` `iconv` `ctype` `fileinfo` | ไฟล์ Excel | เปิดอยู่แล้วเกือบทุกที่ |

**ถ้า `zip` หรือ `gd` ปิดอยู่ → เปิดก่อน** ไม่งั้น `composer install` ล้มทันที

### 3. สร้างฐานข้อมูล MySQL

hPanel → **Databases** → **Management**

จดไว้ 4 ค่า — **Hostinger จะเติม `u123456_` นำหน้าให้เอง**:

```
Database name:  u123456_adprofit
Username:       u123456_admin
Password:       <ที่คุณตั้ง>
Host:           localhost
```

### 4. เปิด SSL (https)

hPanel → **Security** → **SSL** → ติดตั้ง (ฟรี) แล้วเปิด **Force HTTPS**

⚠️ ต้องทำ**ก่อน**ตั้ง `APP_URL` เพราะต้องใส่ `https://`

<a name="มีข้อมูลอยู่แล้ว"></a>
## ⚠️ ถ้ามีฐานข้อมูลที่ใช้งานอยู่แล้ว — อ่านตรงนี้ก่อน

**ห้ามทำตามขั้น "นำเข้าฐานข้อมูล" ด้านล่างเด็ดขาด** — `schema.sql` เป็นคำสั่ง
**ลบตารางแล้วสร้างใหม่** ข้อมูลที่กรอกไว้จะหายหมด

แทนที่จะเดาว่าต้องอัปเดตอะไร ให้ถามฐานข้อมูลตรง ๆ:

```bash
php tools/check-schema.php
```

**อ่านอย่างเดียว ไม่แก้อะไร** · มันจะบอกว่า:
- ตรงกับโค้ดแล้ว → อัปโค้ดใหม่ได้เลย ไม่ต้องทำอะไรกับฐานข้อมูล
- ยังไม่ตรง → **บอกชื่อไฟล์ migration ที่ต้องรัน พร้อมคำสั่งเต็ม**

ทำตามคำสั่งที่มันพิมพ์ออกมา (สำรองข้อมูลก่อนเสมอ) แล้วรันตัวตรวจซ้ำจนขึ้น
"ฐานข้อมูลตรงกับโค้ดแล้ว"

> **ทดลองจริงแล้ว**: สร้างฐานข้อมูลรุ่นเก่าที่มีข้อมูลอยู่ → ตัวตรวจจับได้ครบ 3 ข้อ
> → รัน migration ตามที่บอก → **ข้อมูลอยู่ครบเท่าเดิม** → ตัวตรวจขึ้นเขียว

<a name="ทางที่-1"></a>
## ทางที่ 1 — มี SSH (แพ็กเกจ Premium ขึ้นไป) ⭐ แนะนำ

### 1.1 เปิด SSH และเข้าเซิร์ฟเวอร์

hPanel → **Advanced** → **SSH Access** → เปิด แล้วจดพอร์ต/ผู้ใช้

```bash
ssh -p 65002 u123456@123.45.67.89
```

### 1.2 เตรียมโฟลเดอร์

```bash
cd ~/public_html
ls -A
```

ถ้ามีไฟล์เริ่มต้นของ Hostinger ให้ลบ:

```bash
rm -f index.html index.php default.php
ls -A          # ต้องว่าง (หรือเหลือแค่ . กับ ..)
```

> ⚠️ `git clone` **ลงโฟลเดอร์ที่ไม่ว่างไม่ได้** จะขึ้น
> `fatal: destination path '.' already exists and is not an empty directory`

### 1.3 clone

```bash
git clone https://github.com/MarkkyAlert/ad-profit.git .
```

⚠️⚠️ **จุด `.` ท้ายสุดสำคัญมาก** — แปลว่า "ลงตรงนี้เลย"
ถ้าลืมจะได้ `public_html/ad-profit/` ซ้อนอีกชั้น แล้วเว็บเปิดไม่ขึ้น

**ตรวจทันที:**

```bash
find . -name ".htaccess" | wc -l     # ต้องได้ 9
ls -A .env                            # ต้องขึ้น "No such file" (ถูกต้อง)
```

### 1.4 ติดตั้งไลบรารี

```bash
composer install --no-dev --optimize-autoloader
```

⚠️ **ห้ามลืม `--no-dev`** — ใส่แล้วได้ **7.9 MB** · ไม่ใส่ได้ **66 MB** พร้อมเครื่องมือทดสอบที่ไม่ได้ใช้

> ถ้าขึ้น `composer: command not found` ลอง `php composer.phar install --no-dev --optimize-autoloader`
> หรือ `~/composer.phar` · ถ้าไม่มีเลยให้ใช้[ทางที่ 2](#ทางที่-2)

### 1.5 สร้างไฟล์ตั้งค่า

```bash
cp .env.example .env
nano .env
```

**ค่าที่ต้องแก้ (นอกนั้นปล่อยตามเดิมได้):**

```ini
APP_ENV=production
APP_URL=https://โดเมนของคุณ

DB_HOST=localhost
DB_NAME=u123456_adprofit
DB_USER=u123456_admin
DB_PASS=รหัสผ่านฐานข้อมูล

# ไฟล์บันทึกข้อผิดพลาด — วางไว้ "นอก" public_html จะปลอดภัยกว่า
LOG_FILE=/home/u123456/logs/ad-profit.log

# ระบบอีเมล (ลืมรหัสผ่าน / เปลี่ยนอีเมล)
MAIL_ENABLED=true
MAIL_HOST=smtp.hostinger.com
MAIL_PORT=587
MAIL_USERNAME=no-reply@โดเมนของคุณ
MAIL_PASSWORD=รหัสผ่านอีเมล
MAIL_FROM_ADDRESS=no-reply@โดเมนของคุณ
MAIL_FROM_NAME=วิเคราะห์ยอดขาย
```

บันทึก: `Ctrl+O` → `Enter` → `Ctrl+X`

สร้างโฟลเดอร์เก็บ log:

```bash
mkdir -p ~/logs
```

> ⚠️⚠️ **`APP_URL` ลืมไม่ได้** — ถ้าเว้นว่าง ลิงก์ในอีเมล "ลืมรหัสผ่าน" จะกดจากกล่องจดหมายไม่ได้
> ขณะที่หน้าเว็บบอกว่า "ส่งลิงก์แล้ว" — ผู้ใช้จะเข้าระบบไม่ได้อีกเลย
>
> ⚠️ อีเมลต้องสร้างที่ hPanel → **Emails** → **Email Accounts** ก่อน

### 1.6 นำเข้าโครงสร้างฐานข้อมูล ⚠️ **จุดที่พลาดง่ายที่สุด**

**`database/schema.sql` ฝังชื่อฐานข้อมูล `ad_profit` ไว้ตายตัว**
แต่ฐานข้อมูลจริงของคุณชื่อ `u123456_adprofit`

→ นำเข้าตรง ๆ จะไป**สร้างฐานข้อมูลผิดตัว แล้วของจริงยังว่างอยู่** เว็บจะขึ้น 503

**ตัด 2 บรรทัดนั้นออกก่อน:**

```bash
sed '/^CREATE DATABASE/,/^USE ad_profit;/d' database/schema.sql > ~/schema-hosting.sql
grep -c "CREATE TABLE" ~/schema-hosting.sql     # ต้องได้ 7
```

**แล้วนำเข้า:**

```bash
mysql -u u123456_admin -p u123456_adprofit < ~/schema-hosting.sql
```

พิมพ์รหัสผ่านฐานข้อมูล · ถ้าไม่มีข้อความอะไรขึ้นมา = สำเร็จ

```bash
rm ~/schema-hosting.sql     # ลบทิ้ง ไม่ต้องเก็บ
```

> ⚠️⚠️⚠️ **ไฟล์นี้เป็นคำสั่ง "ลบตารางแล้วสร้างใหม่"**
> ใช้**ครั้งเดียวตอนติดตั้ง** · รันซ้ำตอนมีข้อมูลจริงแล้ว = **ข้อมูลหายหมด**
>
> ⚠️⚠️ **ห้ามนำเข้า `database/sample_data.sql`** — มีบัญชีทดสอบ
> `demo@example.com` พร้อมรหัสผ่านฝังอยู่ในไฟล์ ใครที่เคยเห็นซอร์สโค้ดก็เข้าได้

<a name="ทางที่-2"></a>
## ทางที่ 2 — ไม่มี SSH (แพ็กเกจ Single)

แพ็กเกจเล็กสุดของ Hostinger ไม่มี SSH → รัน `composer` บนเซิร์ฟเวอร์ไม่ได้

**ต้องเตรียม `vendor/` จากเครื่องตัวเองแล้วอัปขึ้นไป**

### 2.1 บนเครื่องตัวเอง

```bash
git clone https://github.com/MarkkyAlert/ad-profit.git ad-profit-deploy
cd ad-profit-deploy
composer install --no-dev --optimize-autoloader
rm -rf .git tests docs .github phpunit.xml phpstan.neon CLAUDE.md handoff.md
rm -f database/sample_data.sql .env.example
```

เหลือประมาณ **9 MB** พร้อมอัป

### 2.2 อัปขึ้นผ่าน File Manager หรือ FTP

hPanel → **Files** → **File Manager** → เข้า `public_html` → ลบไฟล์เริ่มต้น → อัปโหลด

> ⚠️⚠️⚠️ **เปิด "แสดงไฟล์ซ่อน" ก่อนอัปโหลด**
> File Manager: ปุ่ม **Settings** (มุมขวาบน) → **Show hidden files**
> FileZilla: เมนู **Server** → **Force showing hidden files**
>
> ระบบนี้มีไฟล์ `.htaccess` **9 ไฟล์** และเป็นไฟล์ซ่อนทั้งหมด
> **ตัวที่รากคือสิ่งเดียวที่กันไม่ให้ `.env` ถูกดาวน์โหลด** — ตกหล่นแล้วรหัสฐานข้อมูลหลุด

### 2.3 สร้าง `.env` ผ่าน File Manager

สร้างไฟล์ใหม่ชื่อ `.env` แล้ววางเนื้อหาแบบเดียวกับ[ขั้น 1.5](#15-สร้างไฟล์ตั้งค่า)

### 2.4 นำเข้าฐานข้อมูลผ่าน phpMyAdmin

1. โหลด `database/schema.sql` มาที่เครื่องตัวเอง
2. **เปิดด้วย Notepad แล้วลบ 2 บรรทัดแรกนี้ทิ้ง:**
   ```sql
   CREATE DATABASE IF NOT EXISTS ad_profit ...
   USE ad_profit;
   ```
   (บรรทัด `CHARACTER SET` และ `COLLATE` ที่ตามมาด้วย)
3. hPanel → **Databases** → **phpMyAdmin** → เลือกฐานข้อมูลของคุณ → **Import** → เลือกไฟล์ที่แก้แล้ว

<a name="หลังติดตั้ง"></a>
## หลังติดตั้ง — ตรวจ 2 คำสั่ง

### ตัวที่ 1 — ความพร้อมของเซิร์ฟเวอร์ (ต้องมี SSH)

```bash
cd ~/public_html
php tools/check-deploy.php
```

ไล่ตรวจให้: PHP เวอร์ชัน · ส่วนเสริมครบ · `.env` ครบ · **`APP_URL` เป็น URL เต็ม** ·
ต่อฐานข้อมูลได้ · ตารางครบ 7 · เขียน log ได้ · มี `.htaccess`

**ต้องขึ้น "พร้อมใช้งาน"**

### ตัวที่ 2 — ไฟล์ลับโหลดไม่ได้ (รันจากเครื่องไหนก็ได้) ⭐ **ห้ามข้าม**

```bash
php tools/check-live.php https://โดเมนของคุณ
```

ยิงเข้าเว็บจริง ตรวจ **16 รายการ** ว่าโหลดไม่ได้ · และตรวจ**ด้านตรงข้าม**ว่าหน้าเว็บยังเปิดได้

**ต้องขึ้น "ไม่มีไฟล์ลับหลุด"**

> ⚠️⚠️ ตัวนี้ตรวจ `/.git/config` ให้ด้วย — deploy ด้วย `git clone` แล้วโฟลเดอร์ `.git/`
> จะขึ้นไปด้วย ถ้าไม่ถูกปิด **ใครก็ได้ดาวน์โหลดซอร์สโค้ดทั้งหมดย้อนหลัง**
>
> **ถ้าเจอว่า `.env` โหลดได้ → เปลี่ยนรหัสฐานข้อมูลและรหัสอีเมลทันที** ถือว่าหลุดไปแล้ว

<a name="เจอปัญหา"></a>
## เจอปัญหา — ตารางแก้

| อาการ | สาเหตุที่พบบ่อย | แก้ยังไง |
|---|---|---|
| **หน้าขาว ไม่มีอะไรเลย** | ยังไม่ได้ `composer install` | รัน `composer install --no-dev --optimize-autoloader` |
| **503 ระบบขัดข้อง** | ยังไม่ได้นำเข้าฐานข้อมูล หรือนำเข้าผิดฐานข้อมูล | `php tools/check-deploy.php` จะบอกว่าตารางขาดอะไร |
| **ต่อฐานข้อมูลไม่ได้** | `DB_NAME`/`DB_USER` ลืมใส่ `u123456_` นำหน้า | แก้ `.env` |
| **เปิดแล้วเจอ 404 ของ Hostinger** | ลืมจุด `.` ตอน clone → ไฟล์อยู่ใน `public_html/ad-profit/` | ย้ายไฟล์ขึ้นมา หรือ clone ใหม่ |
| **ลิงก์ในอีเมลกดไม่ได้** | `APP_URL` ว่างหรือไม่มี `https://` | แก้ `.env` |
| **ไม่ได้รับอีเมลเลย** | `MAIL_*` ไม่ครบ 4 ค่า หรือยังไม่สร้างอีเมลใน hPanel | สร้างอีเมลก่อน แล้วกรอกให้ครบ |
| **`.env` ดาวน์โหลดได้** | `.htaccess` ที่รากไม่ได้ขึ้นไป | อัปโหลดใหม่โดยเปิด "แสดงไฟล์ซ่อน" **แล้วเปลี่ยนรหัสทั้งหมด** |
| **ตัวเลขในไฟล์ Excel เป็น `2.8E+10`** | คอลัมน์แคบไป | ดับเบิลคลิกที่ขอบคอลัมน์ใน Excel |

<a name="อัปเดต"></a>
## อัปเดตครั้งถัดไป

```bash
cd ~/public_html
git pull
composer install --no-dev --optimize-autoloader
php tools/check-deploy.php
```

`.env` · `logs/` · `uploads/` **ไม่ถูกแตะ** (อยู่ใน `.gitignore`)

> ⚠️ ถ้าการอัปเดตมีการเปลี่ยนโครงฐานข้อมูล จะมีไฟล์ใหม่ใน `database/migrations/`
> **ให้รันเฉพาะไฟล์ migration — ห้ามรัน `schema.sql` ซ้ำ** (มันลบข้อมูลทิ้ง)

## สิ่งที่ **ไม่ต้อง**ทำ

- ❌ **ห้ามนำเข้า `database/sample_data.sql`** (มีบัญชีทดสอบพร้อมรหัสผ่าน)
- ❌ **ห้ามรัน `database/schema.sql` ซ้ำ** หลังมีข้อมูลจริง
- ❌ ไม่ต้องตั้งสิทธิ์ไฟล์อะไรพิเศษ (แอปไม่เขียนไฟล์ใน `public_html`)
- ❌ ไม่ต้องอัป `vendor/` ถ้ามี SSH
